Privacy Policy

Who's That Pokémon?

Short version: We don't collect your name, email, location or contacts, and there are no ads, analytics or tracking.

To let two players play together, the game state is stored in Apple's iCloud (CloudKit). It contains only what is needed to run the game.

What Is Stored

When you create or join an online game, the following is saved in the app's public iCloud database, run by Apple:

  • The game code
  • A random player ID created by the app on your device (not linked to your name or Apple ID)
  • The rules of the game (regions, number of cards, whether own questions are allowed)
  • Which Pokémon each player chose
  • The questions asked and the answers given, including any free-text questions you type
  • Whose turn it is, how many cards are left, and who won

Apple's iCloud also keeps an anonymous identifier for the iCloud account that created or changed a game. We cannot see your name, email address or Apple ID.

Don't write personal information in free-text questions – anyone who knows the game code can read the game.

What Is Not Collected

  • No name, email address or phone number
  • No location, contacts or photos
  • No analytics, tracking or advertising
  • No data is sold or shared with third parties

Third-Party Services

Apple iCloud (CloudKit) stores the game state so both players can see it. Apple's privacy policy applies: apple.com/legal/privacy.

Pokémon images are downloaded from PokéAPI's image repository on GitHub (raw.githubusercontent.com). As with any web request, GitHub receives your device's IP address. No other information is sent.

On Your Device

The app saves the random player ID on your device so you can rejoin your game. It is deleted when you delete the app.

How Long Data Is Kept

Games are kept in iCloud so that a game can be continued. We may delete old games at any time. If you want a game deleted, send us the game code and we will delete it.

Children's Privacy

The app does not ask for or knowingly collect personal information from anyone, including children under 13.

Changes

If this policy changes, the new version will be posted on this page with an updated date.
